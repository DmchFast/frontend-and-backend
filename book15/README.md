# Практическое задание №15: HTTPS + App Shell

## Запуск

### Через `npx`
```bash
npx live-server
```

---

### Через расширение Visual Studio Code `Live Server` by Ritwick Dey

Нажмите `Go Live` в строке состояния, чтобы включить/выключить Live Server.
```
Go Live
```
---

### Через защищённый при помощи `mkcert` с предварительной установкой `Chocolatey`

```bash
npm run http-server 
```

Инструкция и информация как установить Chocolatey тут -> [`CHOCOLATEY_AND_MKCERT.md`](./CHOCOLATEY_AND_MKCERT.md)
